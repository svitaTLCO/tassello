Verify your copy

Check whether your Tassello file (Ufficio or Media) is identical to an official version. The file never leaves your computer: the check happens here, in your browser.

Or drag it into this box.

How it works

For every published version we record the file’s SHA-256 fingerprint: a sequence of 64 characters that changes completely if even a single letter of the file changes. This page computes your file’s fingerprint and looks it up in the lists of official versions of Tassello Ufficio and Tassello Media.

If the file is not recognised as official, someone may have modified it, or a program may have saved it again (for example with the browser’s “Save page as”). Either way, do not use it for important documents and download the official copy.

Advanced check

On Windows you can also compute the fingerprint from the Command Prompt and compare it with the list:

certutil -hashfile tassello-ufficio.html SHA256

For Tassello Media, write tassello-media.html instead of tassello-ufficio.html, here and in the command below.

Every file downloaded from the GitHub releases (Tassello Ufficio from version 1.3.0, Tassello Media from its first release) also carries a provenance signature, which proves that GitHub built it from the public source code. With the GitHub CLI tool:

gh attestation verify tassello-ufficio.html --repo svitaTLCO/tassello

Official channels: svitatlco.github.io/tassello and the GitHub releases. Copies received in other ways, or modified by others, are not official: verify a copy.
