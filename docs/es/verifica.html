Verifica tu copia

Comprueba si tu archivo de Tassello (Ufficio o Media) es idéntico a una versión oficial. El archivo no sale de tu ordenador: la comprobación se hace aquí, en el navegador.

O arrástralo a este recuadro.

Cómo funciona

Para cada versión publicada registramos la huella SHA-256 del archivo: una secuencia de 64 caracteres que cambia por completo si cambia una sola letra del archivo. Esta página calcula la huella de tu archivo y la busca en las listas de versiones oficiales de Tassello Ufficio y de Tassello Media.

Si el archivo no resulta oficial, puede que alguien lo haya modificado o que un programa lo haya vuelto a guardar (por ejemplo con «Guardar como» del navegador). En ambos casos, no lo uses para documentos importantes y descarga la copia oficial.

Verificación avanzada

En Windows también puedes calcular la huella desde el Símbolo del sistema y compararla con la lista:

certutil -hashfile tassello-ufficio.html SHA256

Para Tassello Media, escribe tassello-media.html en lugar de tassello-ufficio.html, aquí y en el comando siguiente.

Cada archivo descargado de las versiones publicadas en GitHub (Tassello Ufficio desde la versión 1.3.0, Tassello Media desde su primera versión publicada) tiene además una firma de procedencia, que demuestra que GitHub lo construyó a partir del código fuente público. Con la herramienta GitHub CLI:

gh attestation verify tassello-ufficio.html --repo svitaTLCO/tassello

Canales oficiales: svitatlco.github.io/tassello y las versiones publicadas en GitHub. Las copias recibidas por otras vías, o modificadas por otros, no son oficiales: verifica una copia.
