Vérifier votre copie

Vérifiez si votre fichier Tassello (Ufficio, Media ou Grafica) est identique à une version officielle. Le fichier ne quitte pas votre ordinateur : la vérification se fait ici, dans le navigateur.

Ou faites-le glisser dans ce cadre.

Comment ça marche

Pour chaque version publiée, nous enregistrons l’empreinte SHA-256 du fichier : une suite de 64 caractères qui change complètement si une seule lettre du fichier change. Cette page calcule l’empreinte de votre fichier et la recherche dans les listes des versions officielles de Tassello Ufficio, de Tassello Media et de Tassello Grafica.

Si le fichier n’est pas reconnu comme officiel, quelqu’un l’a peut-être modifié, ou un programme l’a enregistré à nouveau (par exemple avec « Enregistrer sous » du navigateur). Dans les deux cas, ne l’utilisez pas pour des documents importants et téléchargez la copie officielle.

Vérification avancée

Sous Windows, vous pouvez aussi calculer l’empreinte depuis l’invite de commandes et la comparer à la liste :

certutil -hashfile tassello-ufficio.html SHA256

Pour Tassello Media ou Tassello Grafica, écrivez tassello-media.html ou tassello-grafica.html à la place de tassello-ufficio.html, ici et dans la commande suivante.

Chaque fichier téléchargé depuis les versions publiées sur GitHub (Tassello Ufficio depuis la version 1.3.0, Tassello Media et Tassello Grafica depuis leur première version publiée) porte aussi une signature de provenance, qui prouve que GitHub l’a construit à partir du code source public. Avec l’outil GitHub CLI :

gh attestation verify tassello-ufficio.html --repo svitaTLCO/tassello

Canaux officiels : svitatlco.github.io/tassello et les versions publiées sur GitHub. Les copies reçues par d’autres moyens, ou modifiées par d’autres, ne sont pas officielles : vérifiez une copie.
