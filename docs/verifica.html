Verifica la tua copia

Controlla se il file di Tassello che hai (Ufficio o Media) è identico a una versione ufficiale. Il file non lascia il tuo computer: il controllo avviene qui, nel browser.

Oppure trascinalo in questo riquadro.

Come funziona

Per ogni versione pubblicata registriamo l’impronta SHA-256 del file: una sequenza di 64 caratteri che cambia completamente se nel file cambia anche una sola lettera. Questa pagina calcola l’impronta del tuo file e la cerca negli elenchi delle versioni ufficiali di Tassello Ufficio e di Tassello Media.

Se il file non risulta ufficiale può essere stato modificato da qualcuno, oppure salvato di nuovo da un programma (per esempio con «Salva pagina con nome» del browser). In entrambi i casi non usarlo per documenti importanti e scarica la copia ufficiale.

Verifica avanzata

In Windows puoi calcolare l’impronta anche dal Prompt dei comandi e confrontarla con l’elenco:

certutil -hashfile tassello-ufficio.html SHA256

Per Tassello Media scrivi tassello-media.html al posto di tassello-ufficio.html, qui e nel comando seguente.

Dalla versione 1.3.0 ogni file scaricato dalle release su GitHub ha anche una firma di provenienza, che dimostra che è stato costruito da GitHub a partire dal codice sorgente pubblico. Con lo strumento GitHub CLI:

gh attestation verify tassello-ufficio.html --repo svitaTLCO/tassello
